# Proyecto de Ventas - Power BI

## Descripción
Dashboard desarrollado en Power BI para análisis de ventas utilizando SQL y Excel.

## Herramientas utilizadas
- Power BI
- SQL
- Excel
- Power Query

## KPIs analizados
- Ventas totales
- Clientes activos
- Productos más vendidos
- Métodos de pago
